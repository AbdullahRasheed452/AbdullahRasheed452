<summary><b>Under the hood</b>: architecture diagrams</summary>

<br>

**Restoration & Sketch Studio**: the hard-routed restoration pipeline. A soft mixture-of-experts variant blends the same branches with learned gate weights; a style-conditioned U-Net + PatchGAN generates face sketches. Models are exported to ONNX and served by FastAPI behind a Docker Compose stack.

```mermaid
flowchart LR
    A[Input image] --> B{CNN corruption<br/>classifier}
    B -->|clean| F[Restored image]
    B -->|salt & pepper| C[Specialist<br/>autoencoder]
    B -->|blur| D[Specialist<br/>autoencoder]
    B -->|occlusion| E[Specialist<br/>autoencoder]
    C --> F
    D --> F
    E --> F
```

**VoiceFlow AI**: real-time speech-to-speech translation.

```mermaid
flowchart LR
    A[Microphone] --> B[Web Speech API<br/>live transcript]
    A --> C[OpenAI Whisper<br/>speech-to-text]
    B --> D[Flask API]
    C --> D
    D --> E[Translation<br/>UR · EN · ES · FR · DE · AR]
    E --> F[gTTS<br/>speech synthesis]
    F --> G[Translated audio]
```

</details>
